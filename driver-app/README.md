# ANTS 司机安卓包

界面就是线上司机网页：https://vnhll-production.up.railway.app/driver  
账号、订单、轨迹和网页用的是同一套数据。电脑或手机浏览器打开司机端时，行为与原来一样：页面留在前台才上报，关掉就会停。

安装这个包之后，登录司机账号即开始上报。切到别的应用或锁屏后，通知栏保持「位置上报中」，每 30 秒把当前位置写到正在执行的订单上。通知里的「停止」会结束上报。

一个安装包适用于安卓 8 及以上的手机，不按型号分别发布。安装时需要允许未知来源。第一次打开请允许定位，并允许忽略电池优化。

## 打包

安装包：`driver-app/ANTS-driver.apk`。

这台电脑上的网络代理会截断 Gradle 的本地通信，所以用 `driver-app/android/build-apk.ps1` 直接调用 Android 构建工具打包，不经过 Gradle。
