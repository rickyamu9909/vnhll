## 1. 背景与目标

ANTS 连接货主（工厂/贸易商）与车队/司机，做拖车运输撮合。平台只收佣金，不赚差价。

迭代1 是管理端代运营：客户下单，管理员线下联系司机并代录报价。迭代2 要跑通司机自己参与的主流程：客户出价或询价、司机接单或报价、司机发布运力、平台审核后达成合作。

目标：

- 三端权限隔离，敏感价格不泄露。
- 三条匹配路径可闭环：有出价、无出价、运力匹配。
- 公司主账号可管理司机子账号，并完成接单后派给子账号执行。
- 佣金全局可配置，已发布订单锁定发布时的比例。

## 2. 范围

### 2.1 本次要做

- 平台端、客户端、司机端 Web。
- 客户、公司、个人司机注册与平台审核。
- 公司主账号添加司机子账号与车辆。
- 路径 A、路径 B、运力匹配。
- 订单有效期、流标、客户延长 1 次、自动重新发布。
- 平台审核（超时自动通过）、操作日志。
- 系统配置（佣金与时效）。
- 管理端代客建单（保留）。
- 达成合作后的履约：待执行 → 运输中 → 已送达 → 客户确认完成。
- 站内通知：审核拒绝原因、子账号接受协商后通知主账号。

### 2.2 本次不做

信用分、动态定价、轨迹可视化、虚拟号码、发票、短信/Zalo 推送、App、小程序。

## 3. 入口与角色

| 端 | 路径 | 使用者 | 登录 |
|---|---|---|---|
| 客户端 | `/` | 工厂/贸易商 | 手机号 + 密码 |
| 平台端 | `/admin` | 冠亚物流运营 | 账号 + 密码 |
| 司机端 | `/driver` | 公司主账号、司机子账号、个人司机 | 账号 + 密码 |

三端页面与接口完全隔离。未审核或已拒绝账号不能进入业务功能。

## 4. 账号体系

### 4.1 客户注册

必填：手机号、密码、企业名称、联系人、联系地址。

流程：提交 → 待审核 → 平台通过后激活，可登录建单；拒绝须填写原因，客户可见，可修改后重新提交。

### 4.2 公司注册（司机侧主账号）

必填：营业执照、公司名称、地址、联系方式、登录账号、密码。

流程：提交 → 平台审核 → 通过后激活。主账号可添加司机与车辆。

### 4.3 个人司机注册

必填：身份证、驾驶证、行驶证、车辆照片 6 张、保险证明、联系方式、登录账号、密码。

审核通过后，个人司机按主账号能力使用司机端（可接路径 A、可报价、可发运力），无下属子账号。

### 4.4 司机子账号

仅公司主账号创建，不走公开注册。

主账号录入司机资料和车辆信息，并分配账号密码。子账号登录后可见：我的任务、订单中心、发布运力、个人中心。

子账号规则：

- 路径 A：看不到价格，不能接单。
- 路径 B：可以报价，只能看到自己的报价，看不到佣金和到手价。
- 运力：可以发布并填写期望价，不需要主账号确认；可以接受或拒绝客户协商；接受后通知主账号。

### 4.5 审核

提交资料 → 平台审核 → 通过则账号激活；拒绝则记录原因并通知申请人，申请人可重新提交。

## 5. 建单

客户本人或平台代客均可建单。代客建单必须选择已激活的客户账号，订单归属该客户，出现在该客户的「我的订单」中，后续匹配规则与客户自建完全一致。

### 5.1 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 起运地 | 是 | 省/市 + 详细地址 |
| 起运联系人 | 是 | 接货现场联系人 |
| 起运联系电话 | 是 | 接货现场电话 |
| 目的地 | 是 | 省/市 + 详细地址 |
| 目的联系人 | 是 | 送货现场联系人 |
| 目的联系电话 | 是 | 送货现场电话 |
| 货物类型 | 是 | 普通货 / 危险品 / 其他 |
| 包装 | 是 | 纸箱 / 木箱 / 托盘 / 裸装 / 袋装 / 其他 |
| 货物尺寸 | 是 | 可多行：尺寸模板 + 数量，系统汇总 |
| 异常尺寸备注 | 否 | 超长 / 超宽 / 超高 / 超重等 |
| 车型 | 否 | 选填 |
| 货物重量 | 是 | 总重量，单位：吨 |
| 预约接货时间 | 是 | 精确到小时 |
| 预计送达时间 | 是 | 精确到小时 |
| 目标价格 | 否 | 有值走路径 A，无值走路径 B，单位 VND |
| 备注 | 否 | |

有目标价格与无目标价格不能在发布后随意切换路径。客户在待匹配且无人接单/无有效报价锁定时，可以修改订单后重新发布。

### 5.2 发布时锁定

发布瞬间写入：

- 当时的全局佣金比例
- 等待匹配截止时间 = 发布时间 + 等待匹配时长（默认 24 小时）
- 报价截止时间 = 预约接货时间 − 报价截止提前量（默认 4 小时）
- 订单有效期 = 以上两者中较早的时间

之后修改全局配置，不影响本单。

## 6. 匹配路径

### 6.1 路径 A：客户有目标价

1. 客户建单并填写目标价，例如 2,000,000 VND。
2. 订单进入订单中心。司机主账号看到平台价 2,000,000，以及按本单锁定佣金算出的到手价（20% 时为 1,600,000）。子账号看不到价格，也不能接单。
3. 仅公司主账号或个人司机可接单。接单即锁定，其他司机不能再接。
4. 进入平台审核，时效默认 30 分钟。
   - 通过，或超时未处理：达成合作，状态变为待执行。
   - 拒绝：必须填写理由，写入日志，订单自动回到订单中心重新发布，接单锁定解除。
5. 主账号可将该单分配给本公司子账号。分配后子账号任务状态为待执行。子账号仍看不到佣金和到手价；路径 A 的平台价也不对子账号展示。

### 6.2 路径 B：客户无目标价

1. 客户建单不填目标价。订单中心不显示价格。
2. 主账号与子账号均可报价，同一司机对同一订单在一个发布周期内只能报一次。子账号报价对主账号可见。
3. 到达报价截止时间后开标，进入客户确认。确认时效默认 30 分钟。计时起点可配置为「报价截止后」或「司机首次报价后」。
4. 客户在确认窗内：
   - 同意某一司机：进入平台审核。
   - 拒绝全部：保留日志，系统自动重新发布。
   - 超时未操作：默认同意最低价，再进入平台审核。最低价并列时，取报价时间最早的一条。
5. 平台审核规则同路径 A：通过或超时自动通过则达成合作；拒绝则记录理由并自动重新发布。
6. 若确认窗开始时没有任何报价：不自动成交，订单按流标处理，客户可修改后重新发布。

### 6.3 路径 C：运力匹配

1. 主账号、子账号、个人司机均可发布运力，并填写期望价。子账号不需要主账号确认。
2. 运力大厅向客户展示路线相关信息与期望价。
3. 客户发起匹配：
   - 直接接受期望价：成交价 = 期望价，进入平台审核。
   - 提交协商价：司机收到该价格，可接受或拒绝。接受则成交价改为协商价，进入平台审核。拒绝后客户可再次协商，次数不限。
4. 子账号可以直接接受或拒绝协商。接受后站内通知该公司主账号。
5. 平台审核通过或超时自动通过后达成合作；拒绝则记录理由，该次匹配结束，运力仍可被其他客户匹配，除非司机下架。

## 7. 有效期、延长、流标、重新发布

订单有效期 = min(等待匹配截止时间, 报价截止时间)。

| 先到达的条件 | 结果 |
|---|---|
| 等待匹配时长 | 流标。客户可修改后重新发布，不再审核，直接进入订单中心 |
| 报价截止时间（路径 B） | 进入客户确认，再进入平台审核 |
| 报价截止时间（路径 A 且无人接单） | 流标，客户可修改后重新发布 |
| 客户手动延长 | 每个发布周期可延长 1 次，延长时长取配置值，两个截止时间同步后移 |

以下情况保留操作日志，并自动重新发布（不需要平台再次审核发布资格）：

- 路径 A 平台审核拒绝
- 路径 B 客户拒绝全部报价
- 路径 B 平台审核拒绝

流标不自动重新发布，由客户修改后自己重新发布。

## 8. 履约状态

达成合作之后：

```text
待执行 → 运输中 → 已送达 → 已完成
```

- 待执行：合作刚达成，或主账号已分配给子账号。
- 运输中、已送达：由执行司机或公司主账号推进；平台端也可代为推进。
- 已完成：仅客户确认。客户只能确认自己的订单。

取消规则：

- 待匹配、待确认、已拒绝、流标：客户可取消。
- 已锁定待平台审核、待执行及之后：客户不能自行取消，需联系平台处理。平台可取消并记录原因。

## 9. 佣金

| 项 | 规则 |
|---|---|
| 比例 | 全局统一，平台可配置，默认 20% |
| 基数 | 最终成交价 |
| 路径 A | 成交价 = 客户目标价 |
| 路径 B | 成交价 = 被选中的司机报价 |
| 路径 C | 成交价 = 司机期望价，或客户协商后司机接受的价格 |
| 佣金 | 成交价 × 本单锁定比例 |
| 司机到手价 | 成交价 − 佣金 |
| 生效 | 只影响新发布订单；已发布订单用发布时比例 |

示例（20%）：

- 路径 A：平台价 2,000,000，佣金 400,000，到手 1,600,000。
- 路径 B：司机报价 1,800,000，佣金 360,000，到手 1,440,000。

金额按 VND 整数计算，佣金向下取整到整数，到手价 = 成交价 − 佣金。

## 17. 验收清单

1. 公司注册 → 平台审核 → 登录。
2. 公司添加司机 → 分配账号 → 子账号登录。
3. 客户用手机号注册 → 平台审核 → 登录。
4. 平台可配置佣金比例、确认时效、等待匹配时长、延长时长。
5. 建单必填起运/目的联系人与电话；缺一不可提交。代客建单同样校验，且必须选择客户。
6. 路径 A：有出价 → 订单中心对主账号显示平台价和到手价 → 主账号接单锁定 → 平台审核 → 待执行。
7. 路径 A 子账号看不到价格，不能接单。
8. 路径 A 分配：主账号分配后，子账号任务为待执行。
9. 路径 B：无出价 → 主/子账号报价 → 客户同意 → 平台审核 → 待执行。
10. 主账号能看到本公司全部子账号报价；子账号只看自己的。
11. 路径 B 客户拒绝全部 → 留日志 → 自动重新发布。
12. 路径 B 客户超时 → 默认最低价 → 平台审核。
13. 平台审核拒绝 → 留日志和理由 → 自动重新发布；客户能看到理由。
14. 平台审核超时 → 自动通过。
15. 24 小时无匹配 → 流标 → 客户修改后重新发布，且不再审核发布资格。
16. 客户可延长 1 次。
