# ANTS 操作手册

线上地址：https://vnhll-production.up.railway.app

ANTS 是越南拖车撮合平台。客户发货，司机接单或发布空车，平台只收佣金。货币是越南盾（VND）。页面右上角可以切换中文和越南文。

三个入口共用一个网站，账号不能混用：

| 角色 | 地址 | 谁用 |
|---|---|---|
| 客户 | `/` 或 `/login` | 工厂、贸易商 |
| 司机 | `/driver/login` | 运输公司主账号、个人司机、公司司机子账号 |
| 管理端 | `/admin/login` | 平台运营 |

客户注册在 `/register`，司机注册在 `/driver/register`。注册通过之前不能做业务。匹配成交后不再等平台审核，注册审核仍然要做。

---

## 1. 先看懂订单怎么走

发布时系统按价格决定路径，页面上显示中文，不显示 A、B、C。

| 页面上的名称 | 什么时候出现 | 谁先动手 | 成交后 |
|---|---|---|---|
| 出价接单 | 客户填了目标价 | 公司主账号或个人司机按这个价格接单 | 直接进入待执行 |
| 询价报价 | 客户不填目标价 | 司机报价，客户在确认窗口里选一家 | 客户同意后进入待执行 |
| 运力匹配 | 客户在运力大厅选一辆已发布的空车 | 客户接受司机期望价，或先出协商价 | 接受期望价后直接待执行；协商要等司机同意 |

客户看不到佣金比例、平台佣金和司机到手价。司机子账号在出价单上看不到价格，也不能接这种单；询价单上只能看到自己的报价。

订单页签按节点分，列表字段与订单一致：订单号、状态、路径、起运、目的、联系人、货物、重量、车型、价格、接货时间。

| 页签 | 里面是什么单 |
|---|---|
| 全部 | 当前账号能看到的全部订单 |
| 匹配中 | 还在等司机接单或报价 |
| 已报价 | 仅司机端。这个司机已经报过价，订单仍在匹配或等客户确认 |
| 待确认报价 | 客户和管理端。司机已报价，等客户选择 |
| 待接货 | 已经成交，司机还没提货 |
| 运输中 | 已提货，正在运送 |
| 已送达 | 司机点了已送达，等客户确认 |
| 已完成 | 客户已确认完成 |
| 已取消 | 客户取消、流标或被拒绝 |

默认时效（管理端「系统配置」可以改，只影响之后新发布的订单）：

- 佣金 20%（万分比 2000），发布时锁定，之后改配置不影响已发布订单。
- 等待匹配 24 小时。超时还没人接、没人报价，订单流标。
- 询价的报价截止时间是预约接货前 4 小时。
- 报价截止后，客户有 30 分钟确认报价。超时未确认会流标。
- 客户在匹配中可以延长 1 次，每次 24 小时。
- 运力协商等司机回复的时间是 30 分钟。
- 系统会把距离在 5 公里内的订单和空车互相推荐。

## 2. 客户

客户菜单：我的订单、发布订单、运力大厅、我的匹配。

### 场景 1：第一次注册

1. 打开网站首页，进入企业注册。
2. 填写企业名称、用户名、密码（至少 6 位）、联系人、联系电话。税号和企业地址可以不填。
3. 提交后页面提示等待管理员审核。这时还不能下单。
4. 管理员通过后，用刚才的用户名和密码在首页登录，进入「我的订单」。
5. 如果被拒绝，登录或重新提交时会看到拒绝原因。按原因改资料后再提交。

### 场景 2：发布一张有目标价的订单

适合已经知道愿意付多少钱的货。

1. 登录后点「发布订单」。
2. 起运和目的都要填联系人、电话。这四项是必填。
3. 地址有两种填法，用一种即可：
   - 在「堆场/码头」里搜索并选择。选中后地址会自动带上地点名称，详细街道可以不填。司机熟悉这些地点。
   - 不选堆场码头时，自己选省/市、区/坊/社，并填写详细地址。省和坊必须互相匹配。
4. 填写货物类型、包装。尺寸可以加多行，系统按长宽高和数量算出体积；不填尺寸时可以手写总体积。
5. 重量、车型、预约接货时间、预计送达、备注都可以按实际情况填。接货时间不填时，系统按当前时间加 24 小时。
6. 填写目标价格，单位是越南盾。填了价格，这条单就是「出价接单」。
7. 提交后订单进入匹配池，状态是「匹配中」，出现在「我的订单」的「匹配中」页签。不需要等平台审核。
8. 公司主账号或个人司机按这个价格接单后，订单变成「待接货」。客户在详情里能看到成交价，以及执行司机的姓名。看不到司机到手价和佣金。

### 场景 3：发布一张询价订单

适合还不确定价格、想让司机报价。

1. 发布步骤与场景 2 相同。
2. 目标价格留空。系统把这条单标成「询价报价」。
3. 司机可以多次报价。客户还没确认之前，订单仍是匹配中，其他司机也能报价。
4. 到了确认窗口后，订单进入「待确认报价」。打开订单详情，能看到每家报价和报价方。
5. 点某一行的「同意该报价」。订单进入「待接货」，按该报价成交。
6. 如果报价都不合适，点「拒绝全部报价」。订单重新回到匹配中，司机可以再报。
7. 确认窗口内没有操作，订单会流标，出现在「已取消」一类的关闭页签里。流标后可以修改再发布，或复制成一张新单。

### 场景 4：只选堆场或码头，不写街道

1. 在起运或目的的「堆场/码头」框里输入名字，例如 Cát Lái。
2. 下拉里同一个名字可能有两条：一条是堆场，一条是码头。按实际提箱或还箱位置选择。
3. 选中后，地址自动变成这个地点的名称。省/市和区/坊/社如果系统没有对应行政区，可以留空。
4. 联系人和电话仍然要填。
5. 另一端可以继续选堆场码头，也可以改成普通地址。

### 场景 5：在我的订单里查找

1. 打开「我的订单」。
2. 先点页签，缩小到某一个节点，例如只要看待接货。
3. 再用查询框。可以单独或组合填写：订单号、状态、路径、起运地、目的地、电话、货物、车型、接货时间、价格。
4. 点「查询」。点「重置」恢复全部。
5. 列表右侧可以进详情、查看轨迹、复制新建。匹配中、待确认、流标和被拒绝的订单还可以修改或取消。运输开始之后，客户不能自己取消，需要联系管理员。

### 场景 6：改单、复制、取消、延长

1. 详情页右上角「复制新建」会带出原来的地址、货物和时间，生成一张新订单，不带原来的成交价和佣金。
2. 「修改」只在待审核、已拒绝、匹配中、已流标时出现。改完重新发布，有效期按新的发布时间重算。已经有人接单或进入待确认后不能改。
3. 「取消订单」在运输开始前可用。取消后状态变为已取消。
4. 「延长有效期」只在匹配中出现。默认只能延长 1 次、24 小时。超过次数会提示已达上限。

### 场景 7：从运力大厅找空车

适合司机已经发布了空车，客户想直接用这辆车。

1. 打开「运力大厅」。
2. 用空车位置、目的偏好、车型、发布人、期望价查询。
3. 点「发起匹配」。
4. 开关「直接接受期望价」默认打开。打开时按司机的期望价成交。
5. 填写这票货的起运、目的、联系人、货物。堆场码头的填法和发单一样。
6. 提交。成功提示后订单进入「待执行 / 待接货」，可以在「我的订单」看到。这条单的路径是「运力匹配」。
7. 如果这辆车已经匹配过、被司机取消，或已经找不到，页面会直接写明原因，提交按钮不可用。不要重复点。

### 场景 8：对空车出协商价

司机的期望价不合适时使用。

1. 在发起匹配页关掉「直接接受期望价」。
2. 填写协商价，并填好货物和地址。
3. 提交后提示已发出协商价。这时还没有成交。
4. 到「我的匹配」查看：空车位置、司机期望价、自己出的价格、状态。司机接受后，这里会出现订单链接。
5. 司机拒绝或超时未回复，这票协商结束，需要另选运力或改价再发。

### 场景 9：看司机轨迹并确认收货

1. 订单进入待接货之后，列表里出现「查看轨迹」。
2. 打开后能看到司机上报的位置和当时选择的文字状态，例如前往接货、已接货、运输中、卸货中、已到达、异常。
3. 网页版司机必须开着司机端页面才会上报。安装了 ANTS 安卓包的司机，锁屏或切到其他应用后仍会每 30 秒上报。
4. 司机在订单里点「已送达」后，客户详情出现「确认完成」。
5. 核对货物已收到，再点确认完成。订单进入「已完成」。
6. 没点确认完成之前，订单停在「已送达」。轨迹在司机点「已送达」时停止（此前须已点「前往提货」才会上报）。

## 3. 司机

司机菜单：订单中心、我的订单、我的任务、运力、司机管理、通知。

公司主账号和个人司机可以接出价单、报价、发运力。个人司机没有下属，不能添加子账号。子账号由公司主账号创建，不能接出价单。

### 场景 1：运输公司注册

1. 打开 `/driver/register`，注册类型选「运输公司」。
2. 填写登录账号、密码、联系电话、联系人、公司名称、地址，并上传营业执照照片。
3. 提交后等待平台审核。通过前不能登录做业务。
4. 通过后用账号密码打开 `/driver/login`。

### 场景 2：个人司机注册

1. 注册类型选「个人司机」。
2. 填写账号、密码、电话、联系人。
3. 上传身份证、驾驶证、行驶证、保险证明，以及 6 张车辆照片。缺一张不能提交。
4. 审核通过后，按主账号使用：可以接出价单、报价、发布运力。没有「添加子账号」的能力。

### 场景 3：用手机安装安卓包

1. 安卓 8 及以上安装同一个安装包，不按手机型号区分。
2. 打开后看到的就是司机网站，账号、订单和网页互通。
3. 允许定位，并允许通知。运输中通知栏会显示正在上报位置。
4. 切屏或锁屏后仍每 30 秒上报。通知栏里的停止会结束上报。
5. 苹果手机没有单独安装包，用浏览器打开司机登录页。浏览器切到后台或锁屏后，定位会停。

### 场景 4：接一张出价单

1. 打开「订单中心」。这里是还没成交的出价单和询价单。
2. 用订单号、起运地、目的地、货物、车型、价格等条件查询。
3. 路径显示「出价接单」的，打开详情。能看到平台价、起运、目的、货物和联系电话。
4. 点「接单」。订单从订单中心消失，进入「我的订单」的「待接货」，同时也出现在「我的任务」。
5. 子账号打开出价单时看不到价格，也没有接单按钮。

### 场景 5：给询价单报价

1. 在订单中心打开路径为「询价报价」的订单。
2. 填写报价金额，点「提交报价」。
3. 订单不会因此从大厅消失，其他司机仍可报价。
4. 再次打开同一张订单时，页面顶部会显示已经报过的金额，状态写成「已报价」，按钮变成「修改报价」。输入框里带着上次的价格。不需要为了确认而再提交一次相同价格；只有要改价时才提交。
5. 这张单会出现在「我的订单」的「已报价」页签。客户还没选时，状态是已报价；客户进入确认窗口后，显示「已报价 · 待客户确认」。
6. 客户同意后，订单进入「待接货」。客户拒绝全部报价后，可以再报。

### 场景 6：查看我的订单和我的任务

1. 「我的订单」是自己接过、报过价，或被分配到的全部订单。用页签区分已报价、待接货、运输中、已送达、已完成、已取消。
2. 「我的任务」只放还要执行的单：待接货、运输中、已送达。自己接的单和主账号分给自己的单都会在这里。
3. 两个页面的查询字段与订单字段相同。
4. 如果顶部轨迹条已经出现某张订单，而这张单不在任务里，先下拉刷新。自己接单后还没分配给子账号的单，也应出现在任务里。

### 场景 7：按节点推进运输

成交后打开订单详情，不再使用一个笼统的「推进状态」按钮。按实际进度点节点：

1. 待接货：已接单，还没出发。
2. 前往提货：正在去提货点。
3. 已提货：货已装车。点后需上传装车照片（至少 1 张），确认后订单变为运输中；客户与司机可在订单详情点击查看。
4. 运输中：在路上。
5. 已送达：货已送到。点后需上传卸车完成照片（至少 1 张），确认后等客户确认完成；照片同样可在双方订单详情查看。已送达后不能再点回前面的节点。
6. 车辆异常：车子或现场出问题。点它会记一笔异常，不结束订单。

详情里还有「导航到提货点」和「导航到目的地」，会打开地图搜索这个地址。

公司主账号可以把待接货或运输中的订单分配给本公司子账号：选择司机后点分配。子账号会收到通知，并在「我的任务」看到这张单。只能分配自己接下的订单。

### 场景 8：上报轨迹

1. **启动节点**：司机锁定「前往提货」后才开始上报（成交进入待接货时不上报）。
2. **停止节点**：锁定「已送达」后停止；取消「前往提货」且仍待执行也会停；取消/流标/确认完成同停。
3. **谁报**：点「前往提货」的执行司机（已分配报被分配人，未分配报接单人）。开启后约每 30 秒持续上报，不因速度或静止停报，也不再判定「3 分钟失联」。
4. **地图**：客户/管理查看轨迹时，默认显示起运地到目的地导航路线，并用货车图标标出当前位置（发/收标记）。
5. 网页须保持司机端打开并允许定位；关掉页面后网页上报停止。
6. 安卓包 1.2+：锁屏/切应用仍上报；可在包内选图上传装车/卸车照片。
7. 定位权限被拒绝时到系统设置打开后再回页面。

### 场景 9：发布一条空车运力

1. 打开「运力」，点「发布运力」。
2. 当前位置可以选堆场或码头，也可以写地址。两者至少有一个。
3. 填写可接货的开始和结束时间、车型、载重、期望价。目的偏好、能否进机场、能否进港口按车辆实际情况填。
4. 提交后状态是「可匹配」，客户能在运力大厅看到。
5. 还没被匹配时，可以点「详情」「编辑」「取消」。取消后客户不能再对它发起匹配。
6. 已经匹配成订单的运力不能编辑，也不能当空车取消。页面会提示到对应订单里处理。已匹配的记录可以「查看订单」。

### 场景 10：处理客户的协商价

1. 客户不接受期望价、改出协商价后，运力列表的「协商」栏会出现价格。
2. 点「接受」，按协商价成交，生成订单并进入待执行。公司子账号接受后，主账号会收到通知。
3. 点「拒绝」，这票协商结束，运力仍可被其他人匹配。
4. 超过协商时效没人处理，协商失效。

### 场景 11：公司添加司机

仅运输公司主账号可以做。个人司机打开这个页面不能添加。

1. 打开「司机管理」。
2. 填写姓名、电话、登录账号、密码、车牌、车型、载重，点添加。
3. 把账号和密码交给司机。子账号用司机登录页进入，不需要再注册、也不需要平台审核。
4. 下方列表可用姓名、电话、账号、车牌查询。
5. 子账号登录后：可以看订单中心、给询价单报价、发布运力并自己决定期望价、接受或拒绝协商、执行分配给自己的任务。不能接出价单，看不到出价单的价格，看不到佣金和到手价，也不能再添加司机。

### 场景 12：看通知

打开「通知」。这里有分配任务、协商结果等站内消息。没有短信。

## 4. 管理端

管理端菜单：工作台、订单管理、注册审核、系统配置、客户管理、司机管理、语言包。

匹配成交不需要管理员点通过。管理员要做的是账号审核、代客建单、处理异常订单、改时效和佣金、查看轨迹与日志。

### 场景 1：登录并看工作台

1. 打开 `/admin/login`，使用管理员账号。
2. 工作台有四张卡片：订单总数、待审核订单、客户数、司机数。点卡片进入对应列表。
3. 「待审核订单」统计的是还停在旧审核状态的订单。新发布、新匹配的订单不会进这个数字。

### 场景 2：审核新注册的客户或司机

1. 打开「注册审核」。
2. 查看公司名称、联系人、电话。司机资料可以点开照片：营业执照，或身份证、驾驶证、行驶证、保险和车辆照片。
3. 资料齐全点「通过」。客户可以登录发单；司机可以登录接单。管理员直接创建的司机账号是已激活的，不用再审一次。
4. 资料不符点「拒绝」，并填写原因。申请人能看到原因，改完可以再提交。
5. 已通过的账号如果要停用，到「客户管理」或「司机管理」里停用。停用后不能继续做业务。

### 场景 3：查找客户和司机

1. 「客户管理」维护已注册客户，可查看资料、通过、拒绝、停用。
2. 「司机管理」上方有查询：姓名或公司、电话、账号、车牌、车型、类型。查询同时作用在注册司机和线下司机两张表。
3. 需要平台代开司机账号时，点「新建司机」，选择个人司机或运输公司，填写账号、密码、联系人、电话，并上传对应证件。创建后即为可用账号。

### 场景 4：在订单管理里查单

1. 打开「订单管理」。
2. 查询条件：订单号、客户、状态下拉、起运地、目的地、电话、货物、路径、车型、接货日期从、到。
3. 点查询后，再用页签看某一个节点：全部、匹配中、待确认报价、待接货、运输中、已送达、已完成、已取消。
4. 路径列显示出价接单、询价报价或运力匹配。
5. 列表字段与订单一致，并多一列客户名称。点进详情处理这一张单。

### 场景 5：代替客户发布订单

客户不方便自己发单时使用。订单归客户，不归管理员。

1. 在订单管理点「代客建单」。
2. 先选择一个已经审核通过的客户。
3. 按客户发单的同样字段填写。填目标价就是出价接单，不填就是询价报价。堆场码头可以代替详细地址。
4. 提交后，这张单出现在该客户的「我的订单」，也出现在司机订单中心。后续接单、报价、轨迹都与客户自己发的单相同。

### 场景 6：处理一张异常订单

1. 从订单管理进入详情。
2. 需要把执行进度往前推时，使用推进或把状态设为运输中、已送达。日常进度应由司机在自己的订单里点节点，管理员只在司机无法操作时补记。
3. 详情可以复制通知文字，发给现场联系人。
4. 旧数据如果还停在待平台审核，可以在详情里通过或拒绝。拒绝必须写理由。新匹配不会再进入这一步。
5. 打开「查看轨迹」看司机上报的点和文字状态。打开操作日志看这张单每一次状态变化，包括谁报价、谁接单、司机点了哪个节点。

### 场景 7：修改佣金和时效

1. 打开「系统配置」。
2. 佣金用万分比，2000 表示 20%。
3. 可以改：询价确认从报价截止后开始，还是从第一笔报价后开始；确认时长；等待匹配时长；客户可延长的小时数和次数；报价截止比接货提前几小时；运力协商等待分钟数。
4. 保存后只影响新发布的订单。已经发出的订单继续用发布当时锁定的佣金和截止时间。
5. 客户界面始终不显示佣金和司机到手价。

### 场景 8：改页面文字

打开「语言包」。中文和越南文可以按词条修改。客户、司机看到的按钮和提示会跟着变。业务规则不会因为改文字而改变。

## 5. 一张单从发布到完成的对照

### 出价接单

1. 客户或管理员发布，并填写目标价。
2. 订单进入匹配中，司机在订单中心看到。
3. 主账号或个人司机接单。
4. 订单变为待接货，司机开始上报轨迹。
5. 司机依次点前往提货、已提货、运输中、已送达。
6. 客户查看轨迹，确认完成后订单结束。

### 询价报价

1. 客户或管理员发布，目标价留空。
2. 一个或多个司机报价。司机自己的列表显示已报价。
3. 进入待确认报价后，客户选择一家，或拒绝全部后重来。
4. 同意后与出价接单一样，进入待接货直到客户确认完成。

### 运力匹配

1. 司机先发布空车。
2. 客户在运力大厅选中这辆车。
3. 接受期望价则马上成交；改出协商价则等司机接受或拒绝。
4. 成交后的运输、轨迹和确认完成，与上面两种相同。

中途无人接单、无人报价或客户没有确认，订单流标。客户可以修改后重新发布，或复制一张新单。运输开始后的取消由管理员处理。
