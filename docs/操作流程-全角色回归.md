# ANTS 全角色操作流程（迭代3 修复后）

线上：https://vnhll-production.up.railway.app  
货币：VND。页面可切中文 / Tiếng Việt。

---

## 一、管理端（`/admin/login`）

### 1. 审核注册
1. 打开「注册审核」或「客户管理 / 司机管理」。
2. 查看资料 → 「通过」或「拒绝（填原因）」。
3. 通过后系统只生成一次「注册已通过」通知；用户登录后自动标已读，**不会反复弹窗**。

### 2. 代客建单
1. 「订单管理」→「代客建单」→ 选已激活客户。
2. 填起讫（可堆场/码头或联想地址）、联系人电话、货物；填目标价=出价接单，不填=询价。
3. 提交后订单归该客户，进入匹配池。

### 3. 查单与异常
1. 「订单管理」用查询 + 节点页签筛选。
2. 操作列按钮带底色：详情 / 轨迹 / 复制 / 日志。
3. 详情可看进度、轨迹、日志；司机无法操作时再代推进度。

### 4. 系统配置
佣金（万分比）、等待匹配时长、确认窗口、延长次数等；只影响新单。

## 二、客户（`/` 登录）

菜单：我的订单 · 发布订单 · 运力大厅 · 我的匹配 · **通知**

### 场景 A：出价发单 → 司机接单 → 收货
1. 「发布订单」填起讫、联系人电话；可用地址联想或堆场码头。
2. 看「运输距离 · 时长」（越南路况）。
3. **填写目标价** → 提交 → 引导卡说明「出价接单」与倒计时。
4. 「我的订单 · 进行中 / 匹配中」可查进度；有顺路运力时可在卡片「确认匹配」。
5. 司机接单后状态→待接货；可「轨迹」查看。
6. 司机点「已送达」后，客户点「确认完成」→ 已完成。

### 场景 B：询价发单 → 选报价
1. 发单时**不填目标价**。
2. 司机报价后：客户收到「收到司机报价」通知（通知 tab / 横幅，点查看即已读）。
3. 订单状态变为「已有报价」；详情里可「同意该报价」→ 待接货。
4. 也可等确认窗口，或「拒绝全部报价」后重来。

### 场景 C：运力大厅选空车
1. 「运力大厅」按顺路度看卡片 → 「发起匹配」（有底色按钮）。
2. 接受期望价则直接待执行；协商价则等司机接受（「我的匹配」可查）。

### 通知
1. 打开「通知」查看历史；进入页面会标已读。
2. 「注册已通过」登录后自动消化，不再弹系统通知。

## 三、司机（`/driver/login`）

菜单：订单中心 · 我的订单 · 运力 · 司机管理 · 通知  
（「我的任务」已并入我的订单）

### 场景 A：货源大厅抢单（出价单）
1. 「订单中心」卡片按顺路度排序 → 「抢单」。
2. 成功后离开大厅，进入「我的订单 · 待接货」。

### 场景 B：询价报价
1. 大厅点「报价」提交金额。
2. 订单从大厅消失，进入「我的订单 · 已报价 / 全部」。
3. 客户确认后→待接货。

### 场景 C：发布运力 → 顺路推荐
1. 「运力」→ 发布空车（位置/时间/期望价）。
2. 系统推顺路货源（**每种建议只通知一次**；过期不再刷「已过期」通知）。
3. 「确认匹配」或进订单详情处理。

### 履约与导航
1. 订单详情：「从当前位置导航到提货点 / 目的地」→ 自动定位并画路线（谷歌底图 + 越南路网）；也可「用谷歌地图打开」。
2. 节点：待接货 → 前往提货 → 已提货 → 运输中 → 已送达。  
   - **单击**：选中并锁定（置灰）。  
   - **双击已锁定节点**：取消该节点，写入「取消节点」日志。
3. 「车辆异常」同样可锁定 / 双击取消。

### 公司主账号
「司机管理」添加子账号；待执行单可分配给子账号。

## 四、状态与页签对照（摘要）

| 谁 | 发生了什么 | 订单状态 / 页签 |
|---|---|---|
| 客户发单（有价） | 进匹配池 | 匹配中 |
| 客户发单（无价） | 进匹配池 | 匹配中 |
| 司机报价 | 客户收到通知 | 已有报价；司机「已报价」 |
| 客户同意报价 / 接单 / 运力成交 | 履约开始 | 待接货 |
| 司机点已提货等 | 运输中 | 运输中 |
| 司机已送达 | 等客户 | 已送达 |
| 客户确认完成 | 结束 | 已完成 |
| 超时无人接/无确认 | 流标 | 已取消类 |

## 五、回归检查清单

**客户**  
- [ ] 发单有距离时长；提交有引导  
- [ ] 询价后能收到报价通知且只提醒一次  
- [ ] 运力大厅「发起匹配」为实心按钮  
- [ ] 有独立「通知」菜单；注册通过不再反复弹  
- [ ] 确认完成闭环  

**司机**  
- [ ] 报价后大厅消失、进我的订单已报价  
- [ ] 导航从当前位置到起/讫  
- [ ] 节点单击锁定、双击取消有日志  
- [ ] 撮合过期不再刷通知  

**管理**  
- [ ] 审核只通知一次  
- [ ] 订单操作按钮有底色  
- [ ] 代客建单与客户侧一致  

定时任务：发单后即使无人打开网站，到点仍会流标 / 建议过期（状态变更，不刷过期通知）。
